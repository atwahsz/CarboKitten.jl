CarboKitten (Python)

This folder contains a Python port of the Julia package CarboKitten.jl.

Status
- Only the ALCAP-style workflow is being ported first.
- Units are stored as plain floats (SI units). See docstrings.

Run the example
- Create an environment (uv/pip/venv)
- Install this folder
- Run: python -m examples.alcap_example
